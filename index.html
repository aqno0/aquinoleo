03 / PHILOSOPHY & BACKGROUND

About Leo

I build visual concepts through restraint, contrast, and character.

My work is rooted in black-and-white simplicity. By removing color distractions, form, gesture, and hierarchy take center stage. Whether constructing vector mascot illustrations in Illustrator or building digital web spaces, I believe creative work should feel simultaneously purposeful and playful.

Currently pursuing visual communications and digital arts, experimenting with new formats, generative ideas, and interactive web canvases.

Creative Toolkit

Adobe Illustrator Character Illustration Vector Line Work HTML5 & Modern CSS Interactive JavaScript Visual Identity Minimalist Layouts

Core Disciplines

  • 01
    Maximum Contrast: Deep pitch blacks and brilliant whites create unmatched visual punch.
  • 02
    Expressive Lineage: Every line weight conveys personality, motion, and intention.
  • 03
    Simplicity First: Remove the superfluous so the core subject breathes.
